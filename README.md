# IoT-Smart-Home-System: Cloud-Connected Home Automation & Monitoring

ESP mikrodenetleyicileri (ESP8266/ESP32) ve MQTT/HTTP protokolleri kullanılarak geliştirilen, ev içi çevresel verilerin (sıcaklık, nem, gaz kaçağı) bulut üzerinden anlık takibini ve röle modülleri ile cihaz otomasyonunu sağlayan Nesnelerin İnterneti (IoT) projesidir.

## 📌 Proje Kapsamı ve Özellikler
* **Kablosuz Mikrodenetleyici:** ESP8266 / ESP32 Wi-Fi entegre modül.
* **Çevresel Algılama:** DHT11 (Sıcaklık ve Nem) ve MQ-2 (Duman/Gaz Kaçağı) sensörleri.
* **Yük Kontrolü:** Opto-izolatörlü Röle Kartı ile lamba, fan veya ev aletlerinin uzaktan anahtarlanması.
* **Bulut Entegrasyonu:** MQTT veya Blynk/Firebase bulut platformları üzerinden mobil/web arayüz paneli.
